# v0.13.0 — 2026-09-29

**Migration:** none (wiki and vault formats unchanged). After pull:

```sh
git pull
make refresh BUILD=1
```

Hard-reload the PWA. No new VSIX.

## What changed

Switchbay **0.13.0** hosts curiosity-engine (Graph, filebrowser, atlas) and
okstratr (Agents / observer) through a **same-origin reverse proxy** and
**same-document** mount — no iframes. Core skills start with the daemon.
Settings is a thin client over okstratr’s harness registry. Pack-runs and
ingest-runs from CE workspaces are handled by Switchbay (rail LLM /
`local_ingest`).

Built-in Graph and Agents remain available. Settings → **Proxied skill
embeds** switches Graph to the CE canvas and Agents to the okstratr
observer; turning it off restores the built-ins.

Canonical architecture: [`architecture.md`](../architecture.md).

### Same-origin reverse proxy

- Daemon proxies `/embed/ce/*` → `127.0.0.1:8766` and
  `/embed/okstratr/*` → `127.0.0.1:8767` (loopback-only;
  `SWITCHBAY_*_UPSTREAM` overrides).
- Injects `X-CE-Host: switchbay` / `X-Okstratr-Host: switchbay`.
- Vite dev proxies `/embed` to the daemon.

### Same-document skill mount

- Poll `GET /api/core-skills/status`; wait chrome while `starting` /
  `building_wiki`; mount only when healthy.
- Fetch proxied HTML, rewrite asset URLs, inject markup, and run scripts
  in-panel.
- Soft-reload on wiki `files_changed`; tear down scripts on unmount.

### Dual-mount Graph (CE sidebar + canvas)

- Shell left column: CE Pages|Files (`CeSidebarSlot`) persists across
  Graph / Agents / Editor for CE-backed workspaces when proxied embeds are on.
- Graph pane: CE atlas canvas only (`CeAtlasEmbed`); keeps the atlas warm
  when you leave the tab; `atlas-cache.js` + workspace key for cold Graph cache.
- Prefers `window.CEEmbed.create` when CE provides it; one session
  survives Graph unmount.

### Core-skills auto-start + host_notify

- CE and okstratr always start with the shell.
- Supervised okstratr serve sets `OKSTRATR_HOSTED=switchbay`.
- Rail receives okstratr `host_notify` envelopes.

### Settings → okstratr harness registry

- `/api/okstratr/harness*` thin client; no second Switchbay allowlist.

### Pack + ingest queues

- CE queues pack-runs / ingest-runs under `.workbench/`; Switchbay
  processes them (rail LLM / `local_ingest`, prefer CE drop-ingest endpoint).

## What did **not** change

- v0.12.19 Curate settlement, desk live-worker caps, Web default-off,
  Comms metadata-first, watch folders, Zen/rail geometry — still the
  behavior baseline ([v0.12.19 notes](v0.12.19.md)).
- Graph and Agents are **not** removed; proxied mode is opt-in via Settings.
