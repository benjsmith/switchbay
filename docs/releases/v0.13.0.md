# v0.13.0 — 2026-09-29

**Migration:** no wiki/vault format changes. **Architecture cutover** under the
skill-shell import charter — feature-preserving vs **v0.12.19**. After pull:

```sh
git pull
make refresh BUILD=1
```

Hard-reload the PWA. No new VSIX. Do **not** treat this docs PR as a tag.

## What changed

Switchbay now **hosts** curiosity-engine (Graph / filebrowser / atlas) and
okstratr (Agents / observer) through a **same-origin reverse proxy** and
**same-document** mount — **no iframes**. Core skills **auto-start** with the
daemon. Settings is a **thin client** over okstratr’s harness registry.
CE pack-runs and ingest-runs **drain** into Switchbay (rail LLM /
`local_ingest`).

Canonical architecture: [`architecture.md`](../architecture.md). Developer ADRs remain linked from that map (not removed).

**Migrate-before-thinning:** built-in GraphTab, AgentDashboardTab, and
filebrowser stay until the skill-shell parity checklist is green. Turning on
Settings → **Proxied skill embeds** switches Graph → CE canvas and Agents →
okstratr observer; turning it off restores built-ins.

### Phase 4a — reverse proxy

- Daemon always proxies `/embed/ce/*` → `127.0.0.1:8766` and
  `/embed/okstratr/*` → `127.0.0.1:8767` (loopback-only;
  `SWITCHBAY_*_UPSTREAM` overrides).
- Injects `X-CE-Host: switchbay` / `X-Okstratr-Host: switchbay`.
- Vite dev proxies `/embed` to the daemon.
- ADR: [`ADR-004-same-origin-embed-proxy.md`](../ADR-004-same-origin-embed-proxy.md).

### Embed v2 — same-document mount

- Poll `GET /api/core-skills/status`; wait chrome while `starting` /
  `building_wiki`; mount only when healthy.
- Fetch proxied HTML, rewrite asset URLs, inject markup, **execute** scripts
  (not script-stripped Phase 4a proof).
- Soft-reload on wiki `files_changed`; tear down scripts on unmount.
- ADR: [`ADR-004b-embed-v2-same-document-mount.md`](../ADR-004b-embed-v2-same-document-mount.md).

### Dual-mount Graph (CE sidebar + canvas)

- Shell left column: CE Pages|Files (`CeSidebarSlot`) persists across
  Graph / Agents / Editor for CE-backed workspaces when proxied embeds are on.
- Graph pane: CE atlas canvas only (`CeAtlasEmbed`); soft-park on leave for
  instant return; `atlas-cache.js` + workspace key for cold Graph cache.
- Prefers `window.CEEmbed.create` (CE v1.9.0); session singleton survives
  Graph unmount.
- Doc: [`CE-EMBED-HOOK.md`](../CE-EMBED-HOOK.md).

### Core-skills auto-start + host_notify

- CE + okstratr always auto-start with the shell (Ben lock).
- Supervised okstratr serve sets `OKSTRATR_HOSTED=switchbay`.
- Rail receives okstratr `host_notify` envelopes.

### Settings → okstratr harness registry

- `/api/okstratr/harness*` thin client; no second Switchbay allowlist.
- ADR: [`ADR-005-okstratr-harness-registry-client.md`](../ADR-005-okstratr-harness-registry-client.md).

### Pack + ingest drain

- CE queues pack-runs / ingest-runs under `.workbench/`; Switchbay drains
  them (rail LLM / `local_ingest`, prefer CE drop-ingest endpoint).
- ADRs: [`ADR-006`](../ADR-006-ce-pack-run-drain.md),
  [`ADR-007`](../ADR-007-ce-ingest-run-drain.md).

## What did **not** change

- v0.12.19 Curate settlement, desk live-worker caps, Web default-off,
  Comms metadata-first, watch folders, Zen/rail geometry — still the
  behavior baseline ([v0.12.19 notes](v0.12.19.md),
  [import gate](../handoff/2026-09-20-skill-shell-parity.md)).
- Graph and Agents are **not** removed; proxied mode is opt-in via Settings.
